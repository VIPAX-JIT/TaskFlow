# TaskFlow – Team Task & Project Management System

SESD Semester Project

## Overview
TaskFlow is a full-stack web application designed to help teams manage projects and tasks efficiently.

## Tech Stack
- Backend: Node.js, Express.js, MongoDB
- Frontend: React.js
- Authentication: JWT

## Architecture
Clean layered architecture:
Controller → Service → Repository → Database

## Modules
- User Management
- Project Management
- Task Management
- Dashboard Analytics
